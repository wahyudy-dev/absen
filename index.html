Salin kode ini ke Google Apps Script Spreadsheet Anda untuk database & hosting.

Panduan Singkat Pemasangan Backend:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus semua kode bawaan dan tempelkan kode Code.gs di bawah ini.
  4. Klik Terapkan (Deploy) > Penerapan baru (New deployment).
  5. Pilih Jenis: Web App, Akses: Siapa Saja (Anyone).
  6. Salin URL Web App yang dihasilkan dan tempel di Pengaturan Panel Admin aplikasi ini.
